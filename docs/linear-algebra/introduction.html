Foundations of Linear Algebra

Vectors and Norms​

A vector x∈Rn\mathbf{x} \in \mathbb{R}^nx∈Rn represents a column tuple:

x=[x1x2⋮xn]\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}x=⎣⎢⎢⎢⎢⎡​x1​x2​⋮xn​​⎦⎥⎥⎥⎥⎤​

Inner Product and Orthogonality​

The standard Euclidean inner product is defined as:

⟨x,y⟩=xTy=∑i=1nxiyi\langle \mathbf{x}, \mathbf{y} \rangle = \mathbf{x}^T \mathbf{y} = \sum_{i=1}^n x_i y_i⟨x,y⟩=xTy=i=1∑n​xi​yi​

The Cauchy-Schwarz inequality bounds the inner product:

∣xTy∣≤∥x∥2∥y∥2|\mathbf{x}^T \mathbf{y}| \le \|\mathbf{x}\|_2 \|\mathbf{y}\|_2∣xTy∣≤∥x∥2​∥y∥2​

with equality if and only if x\mathbf{x}x and y\mathbf{y}y are linearly dependent. Two vectors are orthogonal (x⊥y\mathbf{x} \perp \mathbf{y}x⊥y) when xTy=0\mathbf{x}^T \mathbf{y} = 0xTy=0.

Vector Norms​

For x∈Rn\mathbf{x} \in \mathbb{R}^nx∈Rn, the standard ppp-norms are:

  • L1L_1L1​ Norm: ∥x∥1=∑i=1n∣xi∣\|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i|∥x∥1​=∑i=1n​∣xi​∣
  • L2L_2L2​ Norm: ∥x∥2=xTx=∑i=1nxi2\|\mathbf{x}\|_2 = \sqrt{\mathbf{x}^T \mathbf{x}} = \sqrt{\sum_{i=1}^n x_i^2}∥x∥2​=xTx​=∑i=1n​xi2​​
  • L∞L_\inftyL∞​ Norm: ∥x∥∞=max⁡1≤i≤n∣xi∣\|\mathbf{x}\|_\infty = \max_{1 \le i \le n} |x_i|∥x∥∞​=max1≤i≤n​∣xi​∣

Matrix Properties and Subspaces​

For A∈Rm×n\mathbf{A} \in \mathbb{R}^{m \times n}A∈Rm×n, the matrix defines a linear transformation T:Rn→RmT: \mathbb{R}^n \to \mathbb{R}^mT:Rn→Rm via x↦Ax\mathbf{x} \mapsto \mathbf{A}\mathbf{x}x↦Ax.

Fundamental Subspaces​

  1. Range / Column Space: R(A)={Ax∣x∈Rn}⊆Rm\mathcal{R}(\mathbf{A}) = \{\mathbf{A}\mathbf{x} \mid \mathbf{x} \in \mathbb{R}^n\} \subseteq \mathbb{R}^mR(A)={Ax∣x∈Rn}⊆Rm
  2. Kernel / Null Space: N(A)={x∈Rn∣Ax=0}⊆Rn\mathcal{N}(\mathbf{A}) = \{\mathbf{x} \in \mathbb{R}^n \mid \mathbf{A}\mathbf{x} = \mathbf{0}\} \subseteq \mathbb{R}^nN(A)={x∈Rn∣Ax=0}⊆Rn
  3. Row Space: R(AT)⊆Rn\mathcal{R}(\mathbf{A}^T) \subseteq \mathbb{R}^nR(AT)⊆Rn
  4. Left Null Space: N(AT)⊆Rm\mathcal{N}(\mathbf{A}^T) \subseteq \mathbb{R}^mN(AT)⊆Rm

The subspaces form orthogonal complements under the fundamental theorem of linear algebra:

R(A)⊥=N(AT),R(AT)⊥=N(A)\mathcal{R}(\mathbf{A})^\perp = \mathcal{N}(\mathbf{A}^T), \quad \mathcal{R}(\mathbf{A}^T)^\perp = \mathcal{N}(\mathbf{A})R(A)⊥=N(AT),R(AT)⊥=N(A)

The dimensions satisfy the Rank-Nullity Theorem:

rank(A)+nullity(A)=n\text{rank}(\mathbf{A}) + \text{nullity}(\mathbf{A}) = nrank(A)+nullity(A)=n

Matrix Norms and Conditioning​

Norms​

  • Frobenius Norm:
    ∥A∥F=∑i=1m∑j=1naij2=tr(ATA)\|\mathbf{A}\|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n a_{ij}^2} = \sqrt{\text{tr}(\mathbf{A}^T \mathbf{A})}∥A∥F​=i=1∑m​j=1∑n​aij2​​=tr(ATA)​
  • Induced 2-Norm (Spectral Norm):
    ∥A∥2=sup⁡x≠0∥Ax∥2∥x∥2=σmax⁡(A)\|\mathbf{A}\|_2 = \sup_{\mathbf{x} \neq \mathbf{0}} \frac{\|\mathbf{A}\mathbf{x}\|_2}{\|\mathbf{x}\|_2} = \sigma_{\max}(\mathbf{A})∥A∥2​=x=0sup​∥x∥2​∥Ax∥2​​=σmax​(A)

Condition Number​

For invertible A∈Rn×n\mathbf{A} \in \mathbb{R}^{n \times n}A∈Rn×n, the 2-norm condition number is:

κ(A)=∥A∥2∥A−1∥2=σmax⁡(A)σmin⁡(A)\kappa(\mathbf{A}) = \|\mathbf{A}\|_2 \|\mathbf{A}^{-1}\|_2 = \frac{\sigma_{\max}(\mathbf{A})}{\sigma_{\min}(\mathbf{A})}κ(A)=∥A∥2​∥A−1∥2​=σmin​(A)σmax​(A)​

When solving Ax=b\mathbf{A}\mathbf{x} = \mathbf{b}Ax=b, relative perturbations in data propagate according to:

∥δx∥∥x∥≤κ(A)(∥δA∥∥A∥+∥δb∥∥b∥)\frac{\|\delta \mathbf{x}\|}{\|\mathbf{x}\|} \le \kappa(\mathbf{A}) \left( \frac{\|\delta \mathbf{A}\|}{\|\mathbf{A}\|} + \frac{\|\delta \mathbf{b}\|}{\|\mathbf{b}\|} \right)∥x∥∥δx∥​≤κ(A)(∥A∥∥δA∥​+∥b∥∥δb∥​)

BLAS Operational Hierarchy​

Dense linear algebra software divides computational routines into three BLAS tiers based on operational intensity:

BLAS TierSignature ExampleFLOPsData MovementArithmetic Intensity (FLOPs/Byte\text{FLOPs/Byte}FLOPs/Byte)Performance Regime
Level 1y←αx+y\mathbf{y} \leftarrow \alpha \mathbf{x} + \mathbf{y}y←αx+y (AXPY)2n2n2n3n×sizeof(T)3n \times \text{sizeof}(T)3n×sizeof(T)≈2/(3×4)≈0.17\approx 2 / (3 \times 4) \approx 0.17≈2/(3×4)≈0.17Memory Bandwidth Bound
Level 2y←αAx+βy\mathbf{y} \leftarrow \alpha \mathbf{A}\mathbf{x} + \beta \mathbf{y}y←αAx+βy (GEMV)2n22n^22n2(n2+2n)×sizeof(T)(n^2 + 2n) \times \text{sizeof}(T)(n2+2n)×sizeof(T)≈2/sizeof(T)≈0.5\approx 2 / \text{sizeof}(T) \approx 0.5≈2/sizeof(T)≈0.5Memory Bandwidth Bound
Level 3C←αAB+βC\mathbf{C} \leftarrow \alpha \mathbf{A}\mathbf{B} + \beta \mathbf{C}C←αAB+βC (GEMM)2mnk2mnk2mnk(mn+mk+nk)×sizeof(T)(mn + mk + nk) \times \text{sizeof}(T)(mn+mk+nk)×sizeof(T)O(n)O(n)O(n) with tilingCompute Bound

In Level 3 BLAS, data transferred from main memory (HBM/DRAM) into on-chip cache or registers can be reused O(n)O(n)O(n) times. This arithmetic reuse is what allows modern GPU matrix execution pipelines (AMD Matrix Core, NVIDIA Tensor Core) to run at sustained theoretical throughput.
