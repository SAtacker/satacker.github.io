Matrix Decompositions, Solvers, and GPU Acceleration

Direct Solvers for Linear Systems​

Solving Ax=b\mathbf{A}\mathbf{x} = \mathbf{b}Ax=b via explicit matrix inversion (x=A−1b\mathbf{x} = \mathbf{A}^{-1}\mathbf{b}x=A−1b) is both numerically unstable and computationally inefficient. Production solvers factorize A\mathbf{A}A into structured triangular, orthogonal, or diagonal matrices.

LU Decomposition with Partial Pivoting​

For a general non-singular matrix A∈Rn×n\mathbf{A} \in \mathbb{R}^{n \times n}A∈Rn×n, Gaussian elimination with row pivoting computes:

PA=LU\mathbf{P}\mathbf{A} = \mathbf{L}\mathbf{U}PA=LU
  • P∈Rn×n\mathbf{P} \in \mathbb{R}^{n \times n}P∈Rn×n: Permutation matrix tracking row interchanges.
  • L∈Rn×n\mathbf{L} \in \mathbb{R}^{n \times n}L∈Rn×n: Unit lower-triangular matrix (lii=1,  ∣lij∣≤1l_{ii} = 1, \; |l_{ij}| \le 1lii​=1,∣lij​∣≤1).
  • U∈Rn×n\mathbf{U} \in \mathbb{R}^{n \times n}U∈Rn×n: Upper-triangular matrix.

Computational Cost:

  1. Factorization: 23n3\frac{2}{3} n^332​n3 FLOPs (≈13n3\approx \frac{1}{3} n^3≈31​n3 multiply-adds).
  2. Forward substitution (Ly=Pb\mathbf{L}\mathbf{y} = \mathbf{P}\mathbf{b}Ly=Pb): n2n^2n2 FLOPs.
  3. Backward substitution (Ux=y\mathbf{U}\mathbf{x} = \mathbf{y}Ux=y): n2n^2n2 FLOPs.

Pivoting Strategy: At column kkk, the pivot is chosen as max⁡i≥k∣aik(k)∣\max_{i \ge k} |a_{ik}^{(k)}|maxi≥k​∣aik(k)​∣ and swapped into the diagonal position. This ensures multiplier magnitudes satisfy ∣lij∣≤1|l_{ij}| \le 1∣lij​∣≤1, bounding growth factors during Gaussian elimination.

Cholesky Factorization​

When A∈Rn×n\mathbf{A} \in \mathbb{R}^{n \times n}A∈Rn×n is Symmetric Positive Definite (A=AT\mathbf{A} = \mathbf{A}^TA=AT and xTAx>0  ∀x≠0\mathbf{x}^T \mathbf{A} \mathbf{x} > 0 \; \forall \mathbf{x} \neq \mathbf{0}xTAx>0∀x=0), A\mathbf{A}A factors uniquely into:

A=LLT\mathbf{A} = \mathbf{L}\mathbf{L}^TA=LLT

where L\mathbf{L}L is a lower-triangular matrix with strictly positive diagonal elements:

ljj=ajj−∑k=1j−1ljk2,lij=1ljj(aij−∑k=1j−1likljk)(i>j)l_{jj} = \sqrt{a_{jj} - \sum_{k=1}^{j-1} l_{jk}^2}, \qquad l_{ij} = \frac{1}{l_{jj}} \left( a_{ij} - \sum_{k=1}^{j-1} l_{ik} l_{jk} \right) \quad (i > j)ljj​=ajj​−k=1∑j−1​ljk2​​,lij​=ljj​1​(aij​−k=1∑j−1​lik​ljk​)(i>j)

Computational Cost: 13n3\frac{1}{3} n^331​n3 FLOPs (≈16n3\approx \frac{1}{6} n^3≈61​n3 multiply-adds), exactly half the cost of LU factorization. Pivoting is not required for numerical stability.

QR Decomposition and Least Squares​

For rectangular A∈Rm×n\mathbf{A} \in \mathbb{R}^{m \times n}A∈Rm×n with m≥nm \ge nm≥n:

A=QR\mathbf{A} = \mathbf{Q}\mathbf{R}A=QR
  • Q∈Rm×m\mathbf{Q} \in \mathbb{R}^{m \times m}Q∈Rm×m (full) or Rm×n\mathbb{R}^{m \times n}Rm×n (thin/economy): Orthogonal matrix (QTQ=I\mathbf{Q}^T \mathbf{Q} = \mathbf{I}QTQ=I).
  • R∈Rm×n\mathbf{R} \in \mathbb{R}^{m \times n}R∈Rm×n (full) or Rn×n\mathbb{R}^{n \times n}Rn×n (thin): Upper-triangular matrix.

  1. Householder Reflections: Applies orthogonal reflectors Hk=I−2vkvkTvkTvk\mathbf{H}_k = \mathbf{I} - 2 \frac{\mathbf{v}_k \mathbf{v}_k^T}{\mathbf{v}_k^T \mathbf{v}_k}Hk​=I−2vkT​vk​vk​vkT​​ to annihilate subdiagonal columns. Cost: 2n2(m−n3)2n^2(m - \frac{n}{3})2n2(m−3n​) FLOPs. Numerically backward stable.
  2. Givens Rotations: Applies 2×22 \times 22×2 orthogonal rotations to eliminate specific non-zero elements. Ideal for banded or sparse structures.

Linear Least Squares​

To solve min⁡x∥Ax−b∥2\min_{\mathbf{x}} \|\mathbf{A}\mathbf{x} - \mathbf{b}\|_2minx​∥Ax−b∥2​:

Rx=Q1Tb\mathbf{R}\mathbf{x} = \mathbf{Q}_1^T \mathbf{b}Rx=Q1T​b

Unlike forming the normal equations ATAx=ATb\mathbf{A}^T \mathbf{A} \mathbf{x} = \mathbf{A}^T \mathbf{b}ATAx=ATb, which squares the condition number (κ(ATA)=κ(A)2\kappa(\mathbf{A}^T \mathbf{A}) = \kappa(\mathbf{A})^2κ(ATA)=κ(A)2), QR operates directly on A\mathbf{A}A and preserves the original condition number κ(A)\kappa(\mathbf{A})κ(A).

Eigendecomposition​

For square A∈Rn×n\mathbf{A} \in \mathbb{R}^{n \times n}A∈Rn×n, a non-zero vector v\mathbf{v}v satisfying Av=λv\mathbf{A}\mathbf{v} = \lambda \mathbf{v}Av=λv is an eigenvector associated with eigenvalue λ\lambdaλ.

A=VΛV−1\mathbf{A} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^{-1}A=VΛV−1

Accelerator Memory Hierarchy and Tiling​

On hardware accelerators (e.g., AMD ROCm / CDNA / RDNA, NVIDIA CUDA), high computational throughput relies on structured data reuse across memory levels:

[ Global Memory: HBM / GDDR ]   ~1.5 - 5.3 TB/s
            │
            ▼ Tile load into on-chip scratchpad
[ Local Data Share (LDS) / Shared Memory ]   ~15 - 30 TB/s
            │
            ▼ Tile load into registers
[ Vector Register File (VGPRs) ]   ~100+ TB/s
            │
            ▼ Direct operand feed
[ Matrix Core Engine / Tensor Cores ]

GEMM Tiling Hierarchies​

  1. Workgroup / Thread-Block Tile: Partitions C\mathbf{C}C into an Mtile×NtileM_{\text{tile}} \times N_{\text{tile}}Mtile​×Ntile​ submatrix. A workgroup cooperatively loads Mtile×KstepM_{\text{tile}} \times K_{\text{step}}Mtile​×Kstep​ and Kstep×NtileK_{\text{step}} \times N_{\text{tile}}Kstep​×Ntile​ slices of A\mathbf{A}A and B\mathbf{B}B into LDS/shared memory.
  2. Wavefront / Warp Tile: Subdivides the block tile across waves executing matrix-multiply instructions (e.g., AMD v_mfma or NVIDIA mma.sync).
  3. Thread Register Tile: Accumulators stay in vector registers across the entire KKK-dimension accumulation loop, preventing memory spills.

Floating-Point Non-Associativity and Summation​

In IEEE-754 floating-point arithmetic, addition is non-associative:

(a+b)+c≠a+(b+c)(a + b) + c \neq a + (b + c)(a+b)+c=a+(b+c)

Varying execution scheduling or reduction tree topologies across GPU workgroups changes the summation order and causes non-deterministic results.

Compensated Summation​

Kahan compensated summation maintains a running compensation variable ccc to accumulate lost low-order bits:

float kahan_sum(const float* data, size_t n) {
    float sum = 0.0f;
    float c = 0.0f;

    for (size_t i = 0; i < n; ++i) {
        float y = data[i] - c;
        float t = sum + y;
        c = (t - sum) - y;
        sum = t;
    }
    return sum;
}

Compiler Optimization Caveat: Compilers with aggressive floating-point reassociation flags enabled (-ffast-math, -Ofast, or #pragma STDC FP_CONTRACT ON) can optimize (t - sum) - y algebraically to zero. In production code, memory fences, volatile reads, or #pragma STDC FP_CONTRACT OFF are required to preserve compensation semantics.

Reproducible Accumulators​

When bit-level determinism is required across variable thread counts or distributed nodes, reproducible accumulation techniques include:

  • Demmel-Nguyen multi-tier binning: Accumulating floating-point values into fixed-point exponent bins.
  • Superaccumulators (Kulisch): Long fixed-point registers (e.g., hundreds of bits) that cover the full dynamic exponent range without intermediate roundoff.
